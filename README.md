Four quote posts from the public X account @Grevellia1, each quoting a different one of make.fun's newest posts on @makefunai and carrying @makefunai and the play code `makefun-duck-ferret-puffin` in its own words. The posts are the entry: the house reads their reposts, quotes and likes from X, scoring 2 points per repost and per quote and 1 per like, and the top 50 share $500.

The four posts, in order:

1. https://x.com/Grevellia1/status/2125737275493687784 — quotes make.fun's post about Mike Houser building AOD: Age of Dragon with Claude.
2. https://x.com/Grevellia1/status/2125737362617717214 — quotes make.fun's post about Optima Arch's Slotbound grossing nearly $1.33 million in its first week.
3. https://x.com/Grevellia1/status/2125737702016606538 — quotes make.fun's "Make GTA 6" bounty results post.
4. https://x.com/Grevellia1/status/2125737595435155818 — quotes make.fun's post about Tristan Debroise's Yet Another Incremental Game on Steam.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `POSTS.json` to `out/POSTS.json`, byte for byte. The program runs on Node 22, standard library only, with no network access.
